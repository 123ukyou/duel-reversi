## ✨ 正当進化ポイント（追加・改善内容）

1. **Zero-Lag 3D立体石 ＆ 放物線ジャンプ180度宙返りアニメーション (`game.js`)**
   - 13種類すべてのスキンと不壊金石（👑）に**立体的な円柱の厚み（サイドリム）**と**ダイナミック・ドロップシャドウ**を追加。
   - 石を挟んで裏返す際、置いた石から波紋のように時間差（ウェーブ）で石が宙に浮き上がり、空中でクルッと180度回転して着地する3D演出を追加しました（メモリ確保ゼロ設計のためカクつき・ラグは一切発生しません）。
   - 試合中、画面右上の **「🎥 3D立体: ON」ボタン** またはキーボードの **`[V]` キー** で、いつでも3D立体演出と従来の2D標準表示をワンタッチで切り替えられます。

2. **リアルタイムP2Pオンライン通信対戦 (`network.js` + `index.html`)**
   - 画面左上の **「🌐 P2Pオンライン通信」** または決闘設定画面の **「🌐 P2P通信対戦」** からロビーを開き、サーバー契約なし・完全無料で友達とオンライン対戦ができます。
   - ホスト（1P/黒）が選んだ初期配置（310種ドット絵含む）・制限時間・ルールがゲスト（2P/白）へ完全同期され、試合中のカーソル移動・石配置・天空光柱アイテムの落下・クライマックス奇跡までリアルタイムに同期されます。
   - オンライン対戦時は、ホストもゲストも自分のPCで **マウス移動＋クリック** / **WASD＋Space** / **矢印キー＋Enter** のどれでも快適に操作可能です。

3. **既存ロジックの精緻化（バグ修正）**
   - 2P対戦時（`PVP_LOCAL` / `PVP_ONLINE`）にスキン固有のパッシブ能力が一切発動しない「完全実力勝負・フェアバトル」を100%保証。
   - 魔導ダンジョンの「1-2 精鋭戦（ELITE）」クリア後、マウスクリックで進んだ際にも確実に「1-3 大ボス戦（BOSS）」へ進むよう統一。
